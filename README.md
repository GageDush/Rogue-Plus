# Rogue+

Local-first companion application and experimental modular integration for PokéRogue.

## Ownership boundaries

- **GitHub:** Rogue+ source, build scripts, upstream revision pins, generic templates and extension contracts.
- **PokéRogue upstream:** authoritative species IDs, starter costs, game logic and damage calculations.
- **Build pipeline:** generates validated offline references from the pinned upstream commit.
- **User's browser:** decrypted account/run saves and user-created content, retained in IndexedDB. Save files are never committed or sent to a Rogue+ upload endpoint.

The 572 starter IDs, display names and costs are generated by `scripts/generate-game-references.mjs`. The generator was checked against the original catalog before the static file was retired. The generated JSON is ignored by Git and bundled for offline use.

Other legacy game mechanics and asset descriptions remain versioned snapshots until their extractors can be validated. See [DATA_SOURCES.md](docs/DATA_SOURCES.md) for the exact status.

## Development

```bash
cd companion
npm install
npm run dev
```

The companion's `predev` and `prebuild` tasks generate the offline starter reference, so **internet access is needed on the first development/build run**, not when a user opens the installed app.

- `main`: companion application and local-first reference generator.
- `alpha/play-integration`: isolated experimental PokéRogue game bridge and damage preview (not yet a verified playable deployment).
- `companion/src/presets/`: bundled sample strategies, not imported or private user-created content.
- `reference-sources.lock.json`: immutable upstream source commit identifiers.

The original [AppDeploy companion](https://pokerogue-command-center-zgi7j4.v2.appdeploy.ai/) remains separately deployed. Cloudflare Pages Git linkage has not yet been verified.

## Privacy and licensing

See [PRIVACY.md](docs/PRIVACY.md). Do not commit PokéRogue save exports, trainer information, decrypted saves, or secrets. Honor PokéRogue source/asset licensing and attribution if distributing modified upstream game code.
