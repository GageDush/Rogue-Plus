## Implementation

Vite's offline-build plugin hashes the worker template and sorted local output bytes, inserts a deterministic revision and all output paths except source maps/worker itself. This includes bundled game data inside the JS, CSS, HTML, manifest and brand assets. Installation uses Cache.addAll with reload requests: complete precache or rejected installation; a failed new build cannot activate or delete the old active cache. Navigation serves installed HTML rather than pairing network-new HTML with cached-old dependencies.

No skipWaiting, clients.claim or forced reload. A completed update waits until current clients close. Activation removes only earlier Rogue+ shell caches and its legacy shell cache. Other origin caches and IndexedDB/localStorage are untouched. Pinned atlas warming uses bounded 10-second requests; network failure leaves core offline functionality and artwork fallback intact. Actual fetched artwork writes are retained by event.waitUntil. APIs/unrelated resources are not cached. Development doesn't register the placeholder template; production worker updates bypass HTTP script cache.
